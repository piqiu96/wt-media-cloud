# 内容运营统一原型

入口：`/example/operations/production/materials`。统一到本发布管理原型目录，不创建 CHG。

已确认范围：内容生产五页迁入现有发布管理（任务、批次、计划）与运营工具（图片库、封面模板）。运营概览及旧发布管理退役；作品、互动及复刻暂缓迁移。

个人信息与桌面设置也挂入同一工作台：`/example/operations/account/profile` 从统一顶栏头像进入；`/example/operations/desktop/settings` 固定在侧栏左下常驻设置区，仅供桌面端运营；业务菜单单独滚动。账号页复用 `PersonalSettingsPage.vue`，无独立菜单或 iframe；统一用户与昵称/头像来自 `prototypeSession.js`，编辑后同步顶栏，切换业务菜单或身份前保护未保存修改。评审状态使用账号地址的 `?review=account` 选择器，不混入业务导航。旧个人信息与设置地址只跳转到上述路径。

`routes.js` 维护所有菜单及路径；`production/` 保存唯一生产模型和已确认的 HTML 交互，通过 `ProductionPage.vue` 挂入同一 Vue 导航壳，无 iframe。公共 CSS 在生产区域和原生弹窗内隔离。业务函数不调用旧发布执行器。

沿用生产存储键和评审意见；发布资源按来源成片 ID 稳定映射，历史任务快照不改写。原平台“百度”在新版入口映射为“百家号”。旧发布数据不自动导入。新增任务仍按新版的待执行及占用规则处理。

开发/构建预览均支持路径刷新；旧 `?view=publishing`、旧工作台和计划地址兼容跳转。全部能力均为原型演示，不连接正式业务 API 或执行真实平台操作。

发布计划通过 `PlanPage.vue` / `mountPlan(host, adapters)` 在相同外壳内挂载；事件限定在模块内，窗口监听、定时器与嵌入组件在离开时清理。统一菜单由 `OperationsNavigation.vue` 维护，演示身份由 `prototypeSession.js` 共用。正式计划、批次和任务使用同一预览存储；计划页本地存储仅保留筛选偏好和新建续编输入。旧计划按兼容入口只读展示，不自动改写为当前执行记录。

列表名称入口复用 `ResourceNameLink`（默认蓝色、400、悬停加深），主体 ID 复用 `ResourceId` 并独立成列，更新时间统一调用 `formatDateTime` 至分钟。计划基础表单复用 `ResourceDateRange`；负责人不单独展示表单，新建默认当前操作者，编辑保留原值并遵循通用权限。

发布任务选择器继承并锁定前置平台与类目；列表展示最终封面与实际发布标题，任务列表与详情页的账号摘要打开只读账号/窗口 Drawer；快速发布与待执行编辑表单使用只读选择输入框，账号名称显示在框内，通过框内“更换”进入账号选择器。平台默认选项由后端配置文件提供，原型以 `platformPublishingDefaults.js` 的只读数据模拟返回值，前端自动选中，不提供独立配置页或浏览器配置维护能力；默认值只在新建内容时解析，任务保留最终值与配置版本。

一期发布方式为浏览器辅助发布（自动提交）：系统完成上传、填表与最终提交，人工仅处理异常。批次首次执行继续锁定结构与资源映射；未领取且批次未停止的待执行任务可单独修改内容，已排队/执行的任务与历史尝试不允许覆盖。

浏览器回归：在 `web/` 运行 `npm run test:publishing-browser`，自动启动独立预览并执行全部浏览器用例；可在 `--` 后指定用例文件名。默认使用 Playwright Chromium（首次运行先执行 `npx playwright install chromium`），也可通过 `CHROMIUM_EXECUTABLE` 指定本机浏览器。测试使用隔离的示例数据，不使用正式账号。

测试截图、日志、临时图册及调试数据输出到临时目录，不进入源码；浏览器测试使用 `SCREENSHOT_DIR` 指定输出位置。最终代码、必需资源和可复用测试保留。

发布表单按发布资源、发布内容、发布设置组织。最后的发布设置只保留发布方式的禁用输入框与系统执行时间。辅助说明放在字段的问号提示中，不添加重复解释文案。单点时间统一复用 `ResourceDateTime`（TDesign 日期时间选择器、分钟精度），起止范围继续复用 `ResourceDateRange`。

批量配置采用“配置 → 生成并审阅 → 应用配置”。公共设置和模板选择使用两列布局，窄屏单列；封面短标题与模板主标题共用 `shortTitle`。结果逐条展开，生成字段通过铅笔原位编辑，失焦或单行 Enter 保留本次修改、Esc 撤销当前输入；统一应用前不写入原任务。封面文字改变后须更新对应比例的封面。调整批量条件保留人工稿；已应用项锁定，剩余失败项可继续调整。原行并发变化时阻止覆盖，明确确认后基于最新内容重新审阅，保留人工修改。AI 仍为本地演示，不调用外部生成或发布服务。

## CHG107 批次准备预览

打开 `/example/operations/publishing/batches?review=chg107`。追加 `&role=operator` 或 `&role=admin` 可查看普通运营和管理员场景，默认使用高级运营。该入口复用批次原型中的资源配置、内容准备和结果总览。保存允许保留待完善内容和目标缺口，批次详情显示候选配置、四项执行设置、正式任务为零及保存记录。编辑保存仍保留原目标，保存时不生成发布任务。

未带 `review=chg107` 的页面包含后续执行与计划流程演示。

## CHG108 批次执行预览

运行 `npm run dev:example` 后打开 [批次执行走查](http://127.0.0.1:8768/example/operations/publishing/batches?review=chg108)。默认高级运营，追加 `&role=operator` 查看本人批次，或追加 `&role=admin` 查看只读批次。场景全部使用本地演示数据。

| 原型页面／场景 | 走查内容 | 正式页面落点 |
| --- | --- | --- |
| 新建与编辑 · `PublishComposer.vue` | 三步配置复用 107；保存保留候选，创建并发布或开始发布在保存后重新检查；启动失败保留已保存记录 | 共用 `PublishingBatchesPage` 的配置工作区 |
| 列表与启动检查 · `BatchManager.vue` | “启动检查 · 保留目标缺口”展示 3 条候选、正式任务为零。1 条资源不可用，明确确认范围后生成 2 条正式任务，原目标仍为 4 | 批次列表、结果总览及启动检查 |
| 执行情况 · `BatchDetailContent.vue` | “分组执行”配置并发 5，共享 Profile 只允许本组 1 条运行；“组间等待”显示本组结束与下一组最早时间；“异常暂停”保留待人工与原现场 | 批次详情执行情况、组状态和暂停原因 |
| 正式任务、控制与记录 · `BatchDetailContent.vue`、`BatchManager.vue` | 执行组列与原任务详情相连。暂停后可以继续；终止封后续派发，未领取取消但保留占用、未知仍待核实；明确失败可结束整批，失败事实保留 | 批次详情的暂停、继续、终止、结束，以及现有发布任务详情和处理入口 |
| “可信公开 · 30 目标／28 任务／24 公开” | 原目标 30，目标缺口 2，4 条待平台公开，可信发布率 80% | 批次真实公开结果投影 |

组号表示批次内的执行组。可用独立 Profile 少于并发上限时直接按可用数成组；忙、未知占位、现场容量满或没有到时的任务才产生等待。待审核任务仍保留原尝试，不计入公开成功或异常暂停阈值。批次的组间处理与现有任务动作复用既有批次生命周期及发布任务表单。默认旧演示路径及计划页仍用于后续计划设计复核。

浏览器验收使用 `npm run test:publishing-browser -- executionReview.browser.cjs preparationPreview.browser.cjs`。原型产生的发布结果仅用于核对界面、动作与状态。

### CHG109 · 发布计划评审

在 example 服务访问 `/example/operations/publishing/plans?review=chg109`。评审使用同一计划及批次页面，浏览器与预览服务快照按评审模式隔离。示例任务、尝试和结果是合成数据。

| 计划详情 ID | 走查内容 |
| --- | --- |
| `PL-109-PREPARE` / `PL-109-READY` | 全部待执行批次先配置；明确执行后冻结全部配置，只为首批起单 |
| `PL-109-DUPLICATE` | 同平台成片重复，定位两批的候选行 |
| `PL-109-10` / `PL-109-20` / `PL-109-ZERO` | 自动衔接、确认继续、确认跳过 |
| `PL-109-PENDING` / `PL-109-PAUSED` / `PL-109-CHECK` | 人工与未知阻断、计划暂停、停止核验后回原任务核实 |
| `PL-109-PUBLIC` / `PL-109-FINISH` | 审核参与衔接但未公开、保留缺口确认结束 |
| `PL-109-OPERATOR` | 加 `&role=operator` 查看本人计划；加 `&role=admin` 查看管理员只读视角 |

详情路径在 `/plans` 后追加计划详情 ID。批次“详情”打开只读 Drawer；“去配置”和“去处理”进入原批次，完成或返回时回到原计划。
