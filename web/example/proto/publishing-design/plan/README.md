# 发布计划 V1 原型

来源：用户提供的《发布计划 V1 高保真原型全套》，本轮保留其业务交互与本地存储，通过 `PlanPage.vue` 挂载到统一工作台；基础信息、列表与详情复用公共 Vue 组件，原生编辑分区的样式只在计划模块作用域内生效。所有数据均为本地演示，不调用发布、资源或 AI 服务。

- 入口：`/example/operations/publishing/plans`；统一工作台导航与旧计划地址均使用此路径。
- 列表复用公共 Vue 组件，分页默认10条，可选20／50条。表格数据区横向滚动，操作列固定右侧。
- 验证：在 `web/` 运行 `npm run test:publishing-plan`、`npm run test:publishing-prototype`、`npm run test:example`、`npm run build:example`。
- 独立保存键：`wt-publishing-plan-v1`。刷新恢复列表上下文与未完成表单；不读写旧任务、批次原型数据。损坏存档不会被静默覆盖。
- 发布候选仅 B站、百家号、小红书，与现有系统一致；用户输入稿中的抖音资源不作为当前可发布能力。
- 首次启动后不再编辑计划或中途补发；首次人工授权，后续按明确结果和 10% 阈值推进。全部批次执行完并处理未决结果后，按实际公开缺口补量或确认结束；补量不改变原目标。
- 执行结果只有显式回填链接才增加成功数；重试和未知结果持续阻止结束。批次抽屉的「演示反馈控制」只用于模拟结果收敛，不构造成功记录。
- 终止计划停止全部所属未结束批次，取消未开始任务；在途及未知结果保留核实入口，安全收尾前显示“停止中”。单独终止批次不终止其余批次。本地演示不证明正式执行器停止或真实作品发布。

当前原型设计按用户授权直接统一到发布管理，不创建 CHG；设计结论维护在 Workspace `docs/design/publishing.md`，此文件不维护第二套交付状态。

- 标准编辑地址：`/example/operations/publishing/plans/:id/edit`；新建地址：`/example/operations/publishing/plans/new`。旧 HTML 入口只负责兼容跳转，不再创建独立应用。
- 负责人遵守通用角色／团队／类目权限，编辑时保留未改派的历史值；新计划单独保存 `createdBy` 与 `ownerId`。
- 原始截图、日志、图册与阶段计划不保存在源码。浏览器测试通过 `SCREENSHOT_DIR` 将输出放在临时目录；可复用测试保留在 `tests/`。
