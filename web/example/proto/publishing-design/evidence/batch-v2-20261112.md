## 逐页实现

| 页面 / 状态 | 本轮结果 |
| --- | --- |
| 发布范围 | 单平台、类目、批次名称；实时盘点合格账号、可用成片、占用与不可用数量。 |
| 数量与优先级 | 各类目目标相加得到总目标；推荐资源、预计分配、缺口；折叠账号池、批次上限与顺序调整。缺少账号/成片时直接说明缺什么，并可调整发布范围。 |
| 账号与成片匹配 | 按类目分组；自动推荐，支持换账号、换成片、移出、重匹配与资源检查；兼容的人工指定保留。只检查资源，不用内容问题阻断下一阶段。 |
| 资源确认 | 明确说明确认后只读、不创建正式任务、不占用；复制为新草稿可调整资源，原稿保留。 |
| 内容配置 | 左任务列表、右完整采用内容与实际封面；全部、筛选、勾选与范围生成；AI 建议需采用，生成不会覆盖当前版本；人工修改字段有版本保护。移除常驻资源侧栏。 |
| 编辑发布内容 | 六项文案、声明、发布时间、平台相关项、图片与模板；保存校验、放弃编辑确认；模板默认纯净底图，实际渲染后可放大检查。 |
| 结果总览 | 按类目查看实际标题、正文、短标题、声明、发布时间与封面；问题回到具体任务编辑，未通过不能创建。 |
| 创建结果 | 目标、实际任务、缺口分列；缺口须二次确认。先保存创建结果，再进入批次详情；保存未完成时不提前宣告成功，失败可重试保存。 |

## 影响范围与边界

- 批次列表：补齐配置/启动/暂停的动作绑定；新建结果继续进入既有详情。
- 批次详情与任务列表：沿用现有批次和任务关系，创建保持待执行，目标与缺口保留。
- 计划：计划批次骨架继续复用 openBatch；本轮未重做计划页，也未再次完整浏览器走查新建计划。相关关系与调度自动化回归通过。
- 快速发布、图片库、模板编辑器与 common：沿用既有入口和能力，没有重构其页面；仅新批次编辑区调用现有图片/模板和实际封面预览。
- AI 为明确标注的本地演示建议，不调用外部模型；未进行真实平台发布、外部上传或真实任务执行。
- 未完成的验收：用户对本轮视觉、信息密度与操作体验的最终裁定；未将其标记为通过。
