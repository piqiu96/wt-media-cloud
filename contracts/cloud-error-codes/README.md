# Cloud Error Codes

Cloud-owned API and task intake error code definitions.

## Active Definitions

- `v1/identity.yaml`: M2-C1 authentication and authorization errors.
- `v1/media-account.yaml`: M2-C2 validation, visibility, duplicate, and store errors.
- `v1/browser-profile.yaml`: M2-C3 scan identity, expiry, Profile availability, and store errors.
- `v1/agent-runtime.yaml`: M2-C4 binding ticket, node credential, session, and runtime ownership errors.
- `v1/profile-guard.yaml`: M2-C5 sensitive task assignment, runtime, and permit errors.
- `v1/content-production.yaml`: M4-A material visibility, material-usage, transfer lifecycle, local-node, and integrity errors.
