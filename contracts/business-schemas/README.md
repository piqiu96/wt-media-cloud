# Business Schemas

Cloud-owned shared business object schemas.

## Active Definitions

- `v1/identity.yaml`: M2-C1 public user schema without password or session material.
- `v1/media-account.yaml`: M2-C2 public media-account schema without Cookie values.
- `v1/browser-profile.yaml`: M2-C3 confirmed Profile mirror and Bit account binding schemas without local secrets.
- `v1/content-production.yaml`: M4-A material and material-usage public schemas.
- `v1/file-transfer.yaml`: M4-A executor-neutral file-transfer-task schema without local paths, long-lived credentials, or signed URLs.
