# Cloud API Contracts

Cloud-owned public HTTPS JSON API contracts for Web and Desktop consumers.

## Active Contracts

- `v1/identity.openapi.yaml`: M2-C1 login, current user, user administration, password, and session endpoints.
- `v1/media-accounts.openapi.yaml`: M2-C2 authenticated media-account lifecycle, assignment, identification, and tag endpoints.
- `v1/browser-profiles.openapi.yaml`: M2-C3 staged BitBrowser scan, confirmation, and Profile list endpoints.
- `v1/proxies.openapi.yaml`: M2-C proxy ledger, unified capacity, and synchronous Profile proxy write/read-back endpoints.
- `v1/content-production.openapi.yaml`: M4-A material library, the user's material usages, and user-initiated source-download task commands.
