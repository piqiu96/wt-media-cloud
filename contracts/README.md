# Cloud Contracts

Cloud owns the following contract areas.

- `cloud-api`
- `cloud-agent-api`
- `business-schemas`
- `task-schemas`
- `business-enums`
- `cloud-error-codes`

M1 status:

- `cloud-agent-api/v1` is active for Cloud-Agent contract compatibility only.
- Other contract areas remain ownership placeholders until their owning CHGs activate them.
