# Business Enums

Cloud-owned shared enum definitions.

## Active Definitions

- `v1/identity.yaml`: M2-C1 fixed roles and user statuses.
- `v1/media-account.yaml`: M2-C2 platforms, identification states, business states, and login states.
- `v1/browser-profile.yaml`: M2-C3 binding, Profile, scan, and Diff states.
- `v1/content-production.yaml`: M4-A material-video and material-usage enums.
- `v1/file-transfer.yaml`: M4-A cross-domain transfer asset, purpose, scope, and lifecycle enums.
